# Employee Workforce Segmentation

A machine learning project that explores employee groups using
K-Means and Hierarchical Clustering, PCA, and workforce analytics.

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Plotly and Streamlit

## Project Contents
- `notebooks/`: add your completed Google Colab notebook here.
- `results/`: employee cluster labels, PCA coordinates, model comparison.
- `reports/`: Employee Segmentation Report and PCA Summary.
- `app.py`: Streamlit dashboard application.

## How to Run the Dashboard
Install dependencies:
```bash
pip install -r requirements.txt
```

Run:
```bash
streamlit run app.py
```

Keep the `results/` folder in the same project directory as `app.py`.

## Data and Privacy
Check the dataset's original license and attribution requirements.
Do not upload confidential employee information or personal data.
